🔐 Sistema de Autenticação — Front-end

Interface de autenticação desenvolvida com foco em layout moderno, usabilidade e estrutura escalável, servindo como base para um sistema full stack.

🚀 Tecnologias Utilizadas

HTML5 — estrutura semântica

CSS3 — estilização moderna e responsiva

📌 Visão Geral do Projeto

Este projeto simula um sistema de autenticação e atualmente inclui:

🔑 Página de Login

📝 Página de Cadastro

🔄 Página de Recuperação de Senha

🎨 Design moderno e consistente

📱 Layout responsivo

🧩 Estrutura preparada para integração com JavaScript, backend e banco de dados

O foco inicial foi o desenvolvimento da interface e da experiência do usuário, garantindo uma base sólida para evolução full stack.
